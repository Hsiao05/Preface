# 序 · Preface

把零散的想法、文件和大段资料，整理成一段给 AI Agent 的清晰提示词。

常驻 Windows 后台的小窗口，按快捷键呼出，写完需求、拖进文件、粘上资料，
一键复制，粘贴到任意 Agent 里使用。

**名字的含义**：「序」既是序言（写在正文之前，交代意图和材料），
也是秩序（把杂乱的内容理出条理）。

---

## 功能

### 资料管理
- **文件**：拖入窗口或选择，只记录路径和元信息，**不读取文件内容**
- **语料块**：粘贴大段纯文本，带标题，内容会内联进最终提示词
- **@ 引用**：输入 `@` 弹出补全列表，或直接把资料标签拖到原文里
- 编号自动复用：删掉的编号在原文也不再引用时，可以被新资料使用

### 提示词优化
- **按需两步**：需求清楚就一次调用出结果；不清楚才先提问、再出结果
- **澄清面板**：模型提出的问题，可以选选项、自己填、交给 AI 判断，或跳过
- **自动模式判断**：单一修改用简单模式，多步骤任务用 Markdown 模式
- **可编辑结果**：优化完可以直接改，改完一键复制
- **前缀缓存友好**：续写、补救、切换模式都接在同一段对话后面

### 整理碎碎念
把口语化的零散想法理顺成有条理的文字，不套用提示词格式，结果替换原文，可撤销。

### 语音输入
原文输入框右下角的麦克风按钮，点击开始录音，按任意键停止并识别，
结果插在光标处，一次 Ctrl+Z 可整段撤回。

### 其他
- 深浅色模式（跟随设备 / 浅色 / 深色）
- 界面缩放
- 草稿自动保存，「找回之前的内容」可恢复历史版本
- 资料放在前、任务放在最后的长文本组装顺序

## 开发

### 环境要求

- Node.js 20.19+ 或 22.12+
- Windows 10/11

### 安装依赖

```bash
npm install
```

### 启动开发模式

```bash
npm run dev
```

### 运行测试

```bash
npm test
```

### 类型检查

```bash
npm run typecheck
```

### 打包成安装包

```bash
npm run package
```

## 设计原则

**只做三件事**
1. **登记资料**：文件只记路径和元信息，语料块保存全文
2. **组装提示词**：纯函数，不依赖界面和网络，有完整单元测试
3. **调用模型**：四种调用共用一套请求代码

**几条硬性约束**
- 所有模型请求和语音识别请求都由**主进程**发出（界面进程会碰到 CORS，而且 Key 不该出现在那里）
- 文件**只读元信息**，绝不读取内容（格式、批注、公式、版式都是信息）
- API Key 用 `safeStorage` 加密保存，明文不经过 IPC
- 录音**只存内存**，不写磁盘，停止后立即释放麦克风
- 模型的输出不可信：行协议宽松解析 + 兜底，@ 引用要校验
